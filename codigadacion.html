objetivo definicion caracteristicas
HTML HTML significa HyperText Markup Language (Lenguaje de Marcado de Hipertexto). Es el estándar fundamental utilizado para estructurar y desplegar páginas web, definiendo el contenido (párrafos, imágenes, enlaces, tablas) a través de etiquetas. Es un lenguaje de marcado, no de programación, interpretado por navegadores web. HTML (HyperText Markup Language) es el lenguaje estándar para estructurar el contenido de páginas web. Utiliza un sistema de etiquetas () para definir elementos como títulos, párrafos, imágenes y enlaces, permitiendo la creación de hipervínculos (hipertexto). Es multiplataforma, estático y jerárquico, interpretable por cualquier navegador web.
HTML5 HTML5 es la quinta y última revisión del estándar HyperText Markup Language (lenguaje de marcado de hipertexto), diseñado para estructurar y presentar contenido en la web. Lanzado para ser semántico, multiplataforma y adaptable, permite integrar audio, video y gráficos complejos sin complementos externos, siendo fundamental para aplicaciones web móviles modernas. HTML5 es la versión moderna del estándar HTML que mejora la web con soporte nativo multimedia , etiquetas semánticas para mejor estructura , y potentes API (geolocalización, para gráficos, almacenamiento local). Permite sitios web interactivos, rápidos y accesibles sin necesidad de plugins externos.
